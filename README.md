# Smart Supply Chain Nexus

Smart Supply Chain Nexus is a web-based analytics and logistics platform designed to make supply chains more resilient and adaptive.

It solves a real-world problem: when a warehouse runs out of stock, instead of failing the order, the system reroutes it to nearby shops acting as micro-warehouses.

## Overview

The platform provides a dashboard to monitor logistics performance, analyze demand trends, and simulate supply chain behavior.

When inventory is unavailable at a warehouse, the system identifies nearby shops with stock and uses them as alternative fulfillment points.

---

## Key Features

- Real-time analytics (on-time delivery, avg delivery time)  
- Demand forecasting with charts  
- Regional demand insights  
- Smart rerouting when stock is unavailable  
- Micro-warehouse concept using nearby shops  

---

## How It Works

1. Collect and simulate inventory data  
2. Compute performance metrics  
3. Visualize trends  
4. Detect stock shortages  
5. Trigger rerouting to nearby shops  

---

## Tech Stack

React, TypeScript, Tailwind CSS, Recharts, Replit, GitHub

---

## Running the Project

git clone https://github.com/Nehal390/supply-chain.git  
cd supply-chain  
npm install  
npm run dev
